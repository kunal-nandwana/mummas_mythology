# Channel art

- `profile.png` (800x800): YouTube profile picture. YouTube shows it as a circle; everything important is inside the circle.
- `banner.png` (2560x1440): YouTube channel banner. The name and tagline sit inside the safe area for phones, desktop and TV (1546x423 in the centre).
- `*.svg` / `*.html`: sources. `make.js` generates them (`node channel-art/make.js`). Uses the same fonts and colours as the videos (night sky, gold name, Krishna's bansuri with a peacock feather).
