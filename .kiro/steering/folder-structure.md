# Folder structure

- Put each video in its own folder at the repo root, named after the topic, then the format:
  - `<topic>-short-form/` for 9:16 Shorts
  - `<topic>-long-form/` for 16:9 long videos
  - Examples: `barbarik-short-form/`, `hanuman-long-form/`
- Use lowercase topic names with hyphens.
- Do not create generic parent folders like `videos/` or `experiments/`.
- Keep the final version at the top of the topic folder. Put earlier versions in `old-version/` inside it.
