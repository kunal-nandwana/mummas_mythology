# Story brief (copy this into a NEW Kiro session, fill the blanks)

A filled brief lets Kiro get the first version almost right, so you spend fewer credits on fixes.
Only the **Script** is required. Skip any blank you don't care about.

```
Make `<topic>-short-form`   (or -long-form)
Length: about ___ seconds

SCRIPT (my exact words, do not change):
<paste your Hindi script here>

Who tells it: ___ (e.g. Sita's point of view / Mumma telling a child / neutral)
Main feeling: ___ (wonder / sadness / pride / fear / warmth)
The one moment people should remember: ___
Main characters (look): ___ (e.g. Sita: green saree, calm; Ravan: 10 heads)
Place and time of day: ___
Any picture I must have: ___ (e.g. Lanka burning, Hanuman growing huge)
Any picture I do NOT want: ___
Music: my track / scenes library
```

Kiro will first answer with a 6-line difference plan (opening, villain, climax, place + palette, signature visual).
Reply "yes", or change one line.

Then Kiro will:
1. save your script word-for-word as `my-script.md`
2. write `story.js` and run `node tools/build.js <topic>` and `node tools/check.js <topic>`
3. send ONE contact sheet (`<topic>/preview/contact-sheet.png`) for you to review
4. you reply with all fixes in one message, using shot numbers
